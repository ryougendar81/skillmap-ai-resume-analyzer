# SkillMap – AI-Powered Resume Analyzer

SkillMap is an AI-powered web application that helps job seekers evaluate their resumes against specific job descriptions.

The application analyzes the resume, identifies relevant skills, highlights missing skills, and provides personalized recommendations to improve job suitability.

## 🚀 Features

- Resume upload and processing
- Job description analysis
- Resume-to-job skill matching
- Match percentage evaluation
- Identification of missing skills
- Required skills analysis
- Personalized resume improvement suggestions
- Resume history
- AI-powered chatbot assistance
- User registration and login
- Responsive web interface

## 🛠️ Technologies Used

- Python
- Django
- HTML5
- CSS3
- JavaScript
- PostgreSQL / Supabase
- ReportLab
- AI / NLP techniques
